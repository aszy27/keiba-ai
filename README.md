# 🏇 Keiba AI Prediction System (3連複 Sniper V7)

高性能な機械学習モデルとディープラーニングを完全同期型OOF（Out-of-Fold）パイプラインで融合させ、競馬のレース予測および**「3連複の1点勝負」**に特化した高度なマルチステージAI予測システムです。

単なる順位予測にとどまらず、上位馬のスコア分散やギャップからレースの難易度を判定し、3頭が完全に馬券内に沈む確率を割り出す「監督AI（メタモデル）」を搭載しています。

---

## 🧠 システムアーキテクチャ

本予測システムは、以下の5つの独立したモジュール表現をブレンドして最終スコアを算出します。

1. **LightGBM LambdaRank (`ranker`)** レース内での着順（相対順位）の最適化に特化したランキング学習モデル。3連複を射止めるために `NDCG@3` を最大化するようにチューニングされています。
2. **LightGBM Classifier (`clf`)** 対象の馬が3着以内（馬券内）に入線するかどうかの絶対確率を予測する二値分類モデル。不均衡データ（`is_unbalance=True`）に対応。
3. **RacingTransformer (`transformer`)** PyTorchで実装された時系列シーケンスモデル。馬の過去5走の成績動向（着順、タイム差、上がり3F、ペース等）をアテンション機構で解析し、現在の潜在能力を評価します。デビュー馬向けの専用埋め込み（`debut_embedding`）も内蔵。
4. **StrongDAE (`dae`)** Denoising AutoEncoder（ノイズ除去自己符号化器）。基本特徴量にガウシアンノイズを注入して学習させることで、データのブレや欠損に強い32次元の頑健な潜在表現（エンベディング）を抽出します。
5. **Graph Embedding / DeepWalk (`p_vec`)** NetworkXを用いて数万頭の血統マスタから家系図ネットワーク（無向グラフ）を動的に構築。ランダムウォーク（Walk=30, N=10）とWord2Vec（skip-gram）により、血統の相関関係を64次元のベクトル空間に埋め込みます。

### 👑 監督AI (Meta-Model)
予測された上位陣の「1位スコア」「2位スコア」「スコア差（ギャップ）」「標準偏差」「平均値」等のメタ特徴量をインプットとし、そのレースが**「本当に上位3頭で決着する信頼度が高いレースか（3頭完全的中率）」**を0〜100%の自信度として判定します。

```text
keiba/
│

│   ├── features.py             # リークブロック型特徴量エンジニアリング
│   ├── inference.py            # 高速・防弾仕様のDL（Transformer/DAE）推論エンジン
│   └── models_nn.py            # PyTorchニューラルネットワーク定義（Transformer/DAE）
│
├── scrape/                     # スクレイピングモジュール群
│   ├── scrape_horse_ped.py     # ネット競馬DBから血統情報のクローリング
│   ├── scrape_main_data.py     # 指定した年のレース結果（出馬表）を自動フォルダ振分

│   ├── val/                    # 2024年のレース結果（検証用）
│   └── test/                   # 2025年〜2026年のレース結果（テスト・本番用）

├── models/                     # 【Git管理外】学習済みモデル（.pth / .txt / .pkl / .json）

├── evaluate_main.py            # 過去の払戻金データを用いたリアル収支シミュレーター
└── predict_main.py             # 最新の出馬表・追い切りを自動収集して当日の買い目を予測
```

## 🛠️ 実行手順・パイプラインの流れ

システムを利用する際は、必ず以下の **【STEP 1】から【STEP 5】の順番** でスクリプトを実行してください。

### 【STEP 1】環境構築
Python 3.8以上がインストールされている環境で、ターミナルから必要な外部依存ライブラリを一括インストールします。

```bash
pip install -r requirements.txt
```

### 【STEP 2】データの収集とマスタデータの作成
AIの学習ソースとなるレースデータ、およびコースと血統のマスタを構築します。

1. **コースマスタの生成**
   ```bash
   python create_course_master.py
   ```
   * 実行すると、JRA全10場の「直線距離」「高低差」「急坂の有無」を定義した `data/master_course_data.csv` が自動生成されます。

2. **ベースレースデータの取得**
   `scrape/scrape_main_data.py` を開き、設定エリアの `TARGET_YEAR` に取得したい年（例: `2023` や `2026` など）を指定して実行します。
   ```bash
   python scrape/scrape_main_data.py
   ```
   * 指定した年数に応じて、自動的に `data/train/`、`data/val/`、`data/test/` へフォルダが振り分けられ保存されます。
   * 過去データ（2012〜2026年など）を必要に応じてループさせて収集してください。

3. **血統情報の取得**
   ```bash
   python scrape/scrape_horse_ped.py
   ```
   * 収集した全レースデータから登場するすべてのユニークな馬IDを自動抽出し、ネット競馬データベースから「父」「母」のIDを巡回取得して `data/master_horse_data.csv` を作成・追記します。

4. **拡張データ（ラップ・追い切り・払戻金）の取得**
   ```bash
   python scrape/scrape_other_data.py
   ```
   * 存在するすべての `race_data_*.csv` を全自動でスキャンし、まだ取得していない「ラップタイム」「当日の追い切り評価」「レースの払戻金」を差分検知してステルスモードで自動収集・同期します。

### 【STEP 3】血統エンベディングの学習 (DeepWalk)
家系図のネットワーク構造を数値化します。

```bash
python train_graph_embedding.py
```
* `data/master_horse_data.csv` から親子関係のエッジを張り、Word2Vecによるスキップグラム学習を実施します。
* **特徴:** 環境に依存しない不変ハッシュ関数（MD5ベース）を内蔵しているため、別PCでいつ実行しても完全に同じベクトル空間が再現され、`data/horse_vectors.csv` に保存されます。

### 【STEP 4】モデルのメイン学習 (OOF同期パイプライン)
時系列データリークを極限まで遮断した、同期型のメイン学習を行います。

```bash
python train_main.py
```
* **処理の流れ:** TimeSeriesSplit（5分割）によるループが起動します。
* ループ内で、そのFold of 訓練データだけを用いて PyTorchの `RacingTransformer` と `StrongDAE` を学習 ➔ 検証データ（Val）に対して推論特徴量を生成 ➔ そのDL特徴量を結合した上で、LightGBM（Ranker / Classifier）の学習を行います。
* 全Fold終了後、未来情報の混入がゼロのクリーンな状態の `data/oof_features_cache.pkl`（OOFキャッシュ）が生成され、最後に全データをフラットフィッティングした本番用最終モデル重みが `models/` に保存されます。

### 【STEP 5】ハイパーパラメータの全自動最適化 (Optuna)
1点勝負で最も回収率が高くなるようにパラメータを自動チューニングします。

```bash
python optimize_main.py
```
* **Phase 1**: LambdaRankの評価ターゲットに最適化された、3着以内配点（`label_gain`）の報酬探索。
* **Phase 2**: ランカーモデルのハイパーパラメータ（学習率、葉の数、正則化等）の探索。
* **Phase 3**: 3つのモデルスコア（LGB着順、LGB確率、Transformer確率）の「最強の合成比率（ブレンドウェイト）」の探索。
* **Phase 4**: 監督AI（メタモデル）のパラメータチューニング。
* 最適化された結果は自動的に `models/best_params.json` 等に保存され、次回の学習や予測に自動適用されます。

## 📈 評価・検証シミュレーションの使い方

モデルの真の実力（回収率・的中率）を、テストデータ（未来のデータ）を用いてシミュレーションします。

```bash
python evaluate_main.py
```
* **カンニング防止機能:** テストデータの予測対象日における未来情報（オッズや最終的な着順、上がりタイム等）をコード内部で自動的に完全に潰して隠蔽した状態で推論を行います。
* **出力結果:** 監督AIが算出した「自信度（3頭完全的中率）」ごとに、1R=100円均等投資した場合の「勝率」「複勝率」「3連複的中率」「3連単的中率」、および「各種馬券のリアルな回収率（ROI）」の集計テーブルがターミナルに美しく表示されます。これにより、実戦で「自信度何%以上のレースに絞って3連複1点買いをすべきか」の明確なボーダーラインを設定できます。

## 🔮 当日のレース予測（実戦実行）

競馬新聞や当日の出馬表をもとに、最新の買い目を算出します。

1. `predict_main.py` を開き、最上部付近の設定エリアにある `TARGET_IDS` に、予測したいネット競馬の12桁のレースIDを指定します。
   ```python
   # predict_main.py
   TARGET_IDS = [
       "202605021211"  # 予測したい当日のレースID（複数指定可能）
   ]
   ```
2. スクリプトを実行します。
   ```bash
   python predict_main.py
   ```

### 📋 予測出力結果の確認
実行が完了すると、`predict/` フォルダに以下のファイルが自動生成されます。

* **`{レースID}.txt`** (視認用レポート)  
  監督AIによるレース難易度の診断スタンプ（【超激アツ】3連複1点大勝負！/【勝負レース】/【見送り】など）と3頭完全的中率が表示され、下部には各馬の最終合成スコアとともに `👑 本命`, `✨ 対抗`, `🔺 紐` の印が打たれた、そのまま馬券購入に使えるテキストレポートです。
* **`{レースID}_features.csv`** (詳細分析用データ)  
  各馬のディープエンベディング値、特徴量、各モデルが出した生の予測スコアがすべてマージされた詳細なCSVファイルです。
